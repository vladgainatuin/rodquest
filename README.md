# Родквест 🛡⚔️

Семейный таск-трекер в стиле MMORPG. Семья или клан — своя команда, цели — цепочки квестов,
каждый — герой с уровнями, характеристиками и достижениями. С v0.9 семьи, кланы и одиночки
объединяются в гильдии ради общих целей.

Подробное ТЗ: [docs/SPEC.md](docs/SPEC.md)

## Запуск

```bash
flutter pub get
flutter run -d chrome     # веб-версия
flutter run -d windows    # Windows (нужна Visual Studio с C++)
flutter run               # подключённый Android-телефон
flutter test              # тесты игровой механики и синхронизации
```

### Сервер синхронизации (v0.8)

```bash
cd server
python -m unittest discover -s tests   # тесты сервера (SQLite)
python local_server.py 8787            # локальный сервер для разработки
```

В облако (Yandex Cloud Functions + YDB): `rodquest_cloud_setup.bat` (один раз), затем
`rodquest_deploy.bat`. Адрес сервера попадает в сборку через
`--dart-define=RODQUEST_SERVER=https://functions.yandexcloud.net/<id>` (это делает `rodquest_apk.bat`).

## Структура

| Папка | Что внутри |
|---|---|
| `lib/models` | Модели: герой, цель, событие ленты, состояние |
| `lib/logic` | Правила игры: XP, уровни, прогресс, серии, достижения, будильники, таймеры, рекорды, расписание уведомлений, резервная копия |
| `lib/data` | Локальное хранилище, готовые планы |
| `lib/sync` | Синхронизация семьи: сущности, слияние правок, клиент сервера; гильдии (`alliance.dart`) |
| `server` | Сервер синхронизации и гильдий на Python для Yandex Cloud |
| `lib/state` | `GameController` — все действия игрока |
| `lib/screens` | Экраны: Сегодня, Квесты, Бюджет, Лавка, Семья/Клан, Гильдия, Герой, Статистика, онбординг, будильники, таймер, навыки, готовые планы, облако семьи |
| `lib/services` | Звук и уведомления (браузер / приложение), системные уведомления при закрытом приложении, файлы резервной копии |
| `lib/widgets` | Общие виджеты в мультяшном стиле |
| `assets/fonts` | Шрифты Nunito (игровые темы) и PT Sans / PT Serif (взрослые), лицензия OFL |
