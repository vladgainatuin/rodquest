# Родквест 🛡⚔️

Семейный таск-трекер в стиле MMORPG. Семья — гильдия, цели — цепочки квестов,
каждый член семьи — герой с уровнями, характеристиками и достижениями.

Подробное ТЗ: [docs/SPEC.md](docs/SPEC.md)

## Запуск

```bash
flutter pub get
flutter run -d chrome     # веб-версия
flutter run -d windows    # Windows (нужна Visual Studio с C++)
flutter run               # подключённый Android-телефон
flutter test              # тесты игровой механики
```

## Структура

| Папка | Что внутри |
|---|---|
| `lib/models` | Модели: герой, цель, событие ленты, состояние |
| `lib/logic` | Правила игры: XP, уровни, прогресс, серии, достижения, будильники, таймеры, рекорды, расписание уведомлений, резервная копия |
| `lib/data` | Хранилище (сейчас локальное, позже — сервер), готовые планы |
| `lib/state` | `GameController` — все действия игрока |
| `lib/screens` | Экраны: Сегодня, Квесты, Бюджет, Лавка, Гильдия, Герой, Статистика, онбординг, будильники, таймер, навыки, готовые планы |
| `lib/services` | Звук и уведомления (браузер / приложение), системные уведомления при закрытом приложении, файлы резервной копии |
| `lib/widgets` | Общие виджеты в мультяшном стиле |
| `assets/fonts` | Шрифты Nunito (игровые темы) и PT Sans / PT Serif (взрослые), лицензия OFL |
